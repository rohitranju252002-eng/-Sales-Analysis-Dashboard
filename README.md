
# 📊 Sales Analysis Dashboard (Excel)

## Overview

This project is an **interactive Sales Analysis Dashboard** developed in **Microsoft Excel**. The dashboard transforms raw sales data into meaningful business insights using **Pivot Tables, Pivot Charts, Slicers, and Data Visualization techniques**.

The objective of this project is to analyze sales performance, customer behavior, product performance, and delivery metrics through an easy-to-understand and interactive dashboard.

## 📊 Key Business Insights

### Occasion-Based Revenue

* Diwali generated the highest revenue among all occasions.
* Anniversary and Raksha Bandhan also contributed significantly to overall sales.

### Top Performing Products

The highest revenue-generating products include:

* Quia Gift
* Magnam Set
* Harum Pack
* Dolores Gift
* Deserunt Box

### Monthly Sales Trends

* Peak sales were observed during February and August.
* Seasonal sales patterns can be clearly identified through monthly analysis.

### Customer Analysis

* Revenue distribution was analyzed across Male and Female customers.
* Average customer spending was approximately ₹3,521 per order.

### Geographic Analysis

* Sales performance was compared across multiple cities.
* Imphal recorded the highest order quantity among the analyzed locations.
